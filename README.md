MCphone Ultra 模组介绍（Minecraft 1.21.1 / NeoForge）
基于原作者 november521 的 MCphone（MIT 协议）改写增强。版本 v1.9.1-ultra.4。
游戏内手持手机右键打开，内置 47 个 App，按分类列出如下。
文件与开发
文件管理：Web 下载、hex /txt/ JS / Python 编辑器、zip / 7z /rar 解压（支持密码）、压缩打包
JS 编程：内嵌 GraalJS 引擎，写 JS 直接运行
Python：调用系统 Python，写脚本真执行
视频编辑：帧图剪辑、播放、输出
屏幕录制：录制游戏画面（需系统 ffmpeg）
模拟器与娱乐
模拟器：NES / Game Boy / GBA 三合一，ROM 放入 files/roms/ 即可游玩，虚拟按键操作
Bilibili / YouTube：视频列表浏览
内置小游戏：扫雷、2048、贪吃蛇、俄罗斯方块、打飞机、翻牌记忆
图形化游戏制作：在手机里自做小游戏
绘图：16 色调色板、缩放、文字、圆形等图形
网络与社交
浏览器：文字版；安装 MCEF（Modrinth，有 1.21.1 NeoForge 版）后解锁真网页
电话：连接 Simple Voice Chat，拨号建立语音群组，好友按 U 加入即通话
邮件：给在线好友寄信并附带物品（副手一叠即附件），收件人领取进背包
网盘：12 级会员容量（无会员 1 大箱 54 格 → SVIP5 128 大箱、单格堆叠 4096），30 天 = 600 分钟真实时长，无会员存取限速 1 次 / 秒
村民远程交易：潜行 + 右键绑定村民，手机里直接开原版交易界面，等级提升走原版机制
指南针：坐标、朝向、家的方位与距离
随身工具
平板电脑：合成配方为手机 + 下界合金锭 ×4 + 钻石块 ×2 + 钻石 ×4，屏幕更大（190×300），支持横屏
随身合成台：随时合成
随身熔炉：手机内烧炼，VIP 2 倍速、SVIP 4 倍速
随身附魔台：等效书架由 VIP 等级决定（最高满 15）
相机：拍照自动记录坐标 / 维度 / 朝向
闹钟：真实时间提醒，关闭手机也会响
探索地图：自动记录走过地形，可缩放查看；输入坐标后 A* 寻路，在已探索区域找高度差最小的路线并画线导航
VR 联动
平板设置：横屏 / 竖屏切换
原作自带（14 个）
设置、应用商店、聊天、相机、相册、音乐、末影箱、笔记、传送石（需 Waystones）、浏览器（需 MCEF）、时钟、天气、阅读、任务
安装
安装 Minecraft 1.21.1 + NeoForge 21.1.x
将 mcphone-1.9.1.jar 放入 .minecraft/mods/
进游戏合成手机（或按快捷键）使用
选装模组：MCEF（真网页浏览器）、Simple Voice Chat（电话）、Curios（手机挂饰品栏）、Waystones（传送石）。
